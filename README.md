# MYJAT — Membership Website

MYJAT is a PHP-based website project focused on membership registration, member services, and information pages.

## Live Website
https://myjat.in

## Tech Stack
- PHP
- HTML5
- CSS3
- JavaScript
- MySQL / MariaDB
- Git and GitHub
- Laragon for local development

## Project Structure
- `vip/` — Application bootstrap, routing, configuration, and rendering
- `includes/core/` — Core membership modules
- `includes/backend/` — Backend membership operations
- `includes/frontend/` — Registration and member-facing modules
- `includes/pages/` — Website content pages
- `assets/` — Frontend assets and styling

## Development Highlights
- Modular PHP application structure
- Centralized route handling
- Reusable CSS architecture
- Environment-based database configuration
- Membership-related modules and page routing

## Status
The website is live. Features and responsive behaviour continue to be reviewed and improved.
